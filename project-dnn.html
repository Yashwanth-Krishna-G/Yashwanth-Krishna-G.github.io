CNN-Based Surrogate Model for Reynolds-Number-Parameterized Vortex Shedding Flows

PyTorch & Deep LearningFortranOpenMP Ongoing Project

An ongoing initiative to bridge traditional Computational Fluid Dynamics (CFD) with Deep Learning. The overarching goal is to train a Convolutional Neural Network (CNN) to instantly predict unsteady fluid flow fields across varying Reynolds numbers, drastically reducing the computational bottleneck of numerical integration.

Phase 1: High-Fidelity Data Generation (Completed)

To train a robust surrogate model, a massive, high-fidelity dataset of fluid behavior was required. Rather than relying on external datasets, I engineered a custom fractional-step Navier-Stokes solver in Fortran.

The data-generation pipeline was parallelized using OpenMP across 6 threads. This allowed for the automated batch-generation of unsteady 2D vortex shedding simulations across a comprehensive Reynolds number sweep (Re 60–180). The pipeline efficiently dumps the velocity and pressure fields into raw binary snapshots, which are then mapped and parsed directly into multi-dimensional NumPy arrays via a custom Python data loader.

# Extracting Fortran binary dumps into PyTorch-ready tensors
def load_fluid_snapshot(filepath, nx=666, ny=360):
    raw_data = np.fromfile(filepath, dtype=np.float64)

    # Slice 1D binary array into physics fields
    u_flat = raw_data[0 : nx*ny]
    v_flat = raw_data[nx*ny : 2*nx*ny]
    p_flat = raw_data[2*nx*ny : 3*nx*ny]

    # Reshape using Fortran memory ordering
    u = u_flat.reshape((nx, ny), order='F')
    v = v_flat.reshape((nx, ny), order='F')
    p = p_flat.reshape((nx, ny), order='F')
    return u, v, p

Snippet from the custom Python pipeline used to parse binary Fortran data into ML-ready arrays.

Phase 2: Spatiotemporal Surrogate Modeling (Ongoing)

With the foundational dataset generated, the project is currently in the active modeling phase. I am building an end-to-end deep learning pipeline using PyTorch.

The objective is to train a Convolutional Neural Network (CNN) to map the spatiotemporal characteristics of the Von Kármán vortex street. Once fully trained and validated, this surrogate model will be capable of predicting accurate velocity and pressure contours for entirely unseen Reynolds numbers—reducing the time to acquire a flow field approximation from hours of numerical iteration down to a fraction of a second.
